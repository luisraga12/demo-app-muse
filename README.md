# Mis Postulaciones — Demo App

App demo hecha por Muse para mostrar cómo trabaja en su máquina virtual.

## Qué hace
Tracker simple de postulaciones de trabajo: agrega empresa, puesto y estado, y se guarda en el navegador (localStorage). Ya trae precargadas las postulaciones reales de Luis de Nov 2026: ACI/Tampico, Neumo y NativApps.

## Archivos
- `index.html` — estructura de la página
- `style.css` — estilos
- `app.js` — lógica (agregar y guardar postulaciones)

## Cómo correrla
Abre `index.html` en cualquier navegador. No necesita servidor ni instalación.

## Cómo se hizo
1. Muse escribió los 3 archivos en su máquina virtual (Linux).
2. Los subió a GitHub al repo `luisraga12/demo-app-muse`.
3. Sin descargar Visual Studio: el código se escribe directo, se prueba y se sube con git.
